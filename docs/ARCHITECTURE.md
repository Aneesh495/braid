# System Architecture

## 1. Overview and Design Principles

`braid` is an end-to-end fault-tolerant quantum compilation, stabilizer circuit synthesis, and topological error correction engine. The system is designed around the mathematical correspondence between the $n$-qubit Clifford group $\mathcal{C}_n$, the Pauli group $\mathcal{P}_n$, and the binary symplectic group $\mathrm{Sp}(2n, \mathbb{F}_2)$.

## 2. Core Subsystems

### 2.1 Pauli and Symplectic Subsystem (`lib/pauli.gd`, `lib/pauli.gi`)
The foundational algebra represents each $n$-qubit Pauli operator as a pair of binary vectors $(x \mid z) \in \mathbb{F}_2^{2n}$ with a phase exponent $\delta \in \{0, 1, 2, 3\}$ representing $i^\delta$:
- Addition of symplectic vectors corresponds to Pauli multiplication modulo phases.
- The phase update tracks signs generated by the commutation of single-qubit Pauli matrices ($X Z = -i Y$).
- Commutation relations are evaluated via the standard symplectic bilinear form:
  $$\langle u, v \rangle = u_x \cdot v_z \oplus u_z \cdot v_x \pmod 2$$
  where $\langle u, v \rangle = 0$ implies commutation and $\langle u, v \rangle = 1$ implies anticommutation.

### 2.2 Gottesman-Knill Stabilizer Tableau (`lib/tableau.gd`, `lib/tableau.gi`)
The stabilizer tableau maintains full state information for an $n$-qubit stabilizer state using a $(2n) \times (2n+1)$ boolean matrix:
- Rows $1 \le i \le n$: Destabilizers $r_i$
- Rows $n+1 \le i \le 2n$: Stabilizers $g_i$
- Column $2n+1$: Phase vector $s \in \{0, 1\}$ representing signs $\pm 1$.

State operations:
1. **Hadamard ($H$)**: Swaps $x$ and $z$ columns, updating the sign bit.
2. **Phase ($S$)**: Adds $x$ column into $z$ column, updating the sign bit.
3. **CNOT**: Adds control $x$ to target $x$, and target $z$ to control $z$.
4. **Measurement**:
   - Random case: when measured Pauli anticommutes with at least one stabilizer generator, pivots that generator, updates all other anticommuting rows, and inserts the measurement operator into the tableau.
   - Deterministic case: when measured Pauli commutes with all stabilizers, computes the outcome eigenvalue from the linear combination of destabilizer rows.

### 2.3 Symplectic Synthesizer (`lib/clifford.gd`, `lib/clifford.gi`)
Clifford operations on $n$ qubits are isomorphic to elements of the symplectic group $\mathrm{Sp}(2n, \mathbb{F}_2)$ up to Pauli phases. The synthesizer executes:
1. Extraction of the $2n \times 2n$ symplectic matrix representation of any Clifford gate sequence.
2. Bruhat decomposition of $\mathrm{Sp}(2n, \mathbb{F}_2)$ into canonical generators.
3. CNOT synthesis using linear reversible logic synthesis (Gaussian elimination over $\mathbb{F}_2$).
4. Circuit optimization: cancel adjacent self-inverse gates, commute Pauli operators through Clifford gates, and merge phase rotations.

### 2.4 Quantum Error Correction Framework (`lib/css.gd`, `lib/surface.gd`, `lib/qldpc.gd`)
The QECC subsystem provides three distinct families of quantum codes:
1. **Calderbank-Shor-Steane (CSS) Codes**:
   Constructed from classical linear code dual pairs $C_1, C_2^\perp$ satisfying $C_2^\perp \subset C_1$.
   Includes the Steane $[[7,1,3]]$ code, Shor $[[9,1,3]]$ code, and classical Golay/Reed-Muller embeddings.
2. **Topological Surface Codes**:
   Rotated planar lattices characterized by distance $d$:
   - $n = d^2$ data qubits arranged on vertices.
   - $(d^2 - 1) / 2$ weight-4 and weight-2 $X$-type star stabilizers.
   - $(d^2 - 1) / 2$ weight-4 and weight-2 $Z$-type plaquette stabilizers.
   - Logical operators $\bar{X}$ and $\bar{Z}$ running between opposing rough and smooth boundaries.
3. **Group-Algebra Quantum LDPC (QLDPC) Codes**:
   Constructed from finite group rings $\mathbb{F}_2[G]$:
   - Generalized Bicycle (GB) codes.
   - Hypergraph Product (HP) codes from pair of classical LDPC seed codes.
   - Lifted Product (LP) codes providing constant-rate and linear-distance scalings.

### 2.5 Syndrome Decoding Subsystem (`lib/decoder.gd`, `lib/decoder.gi`)
1. **Lookup Table (LUT) Decoder**: Exact minimum-weight coset decoder indexing precomputed syndrome tables for small codes ($n \le 15$).
2. **Minimum-Weight Perfect Matching (MWPM) Blossom Decoder**:
   - Constructs complete syndrome defect graphs from non-trivial stabilizer measurement outcomes.
   - Computes all-pairs shortest paths using Manhattan distances on planar surface lattices.
   - Solves the maximum-weight/minimum-weight matching via Edmonds blossom algorithm.
   - Returns recovery Pauli operators that neutralize error chains.
3. **Belief Propagation with Ordered Statistics Decoding (BP-OSD)**:
   - Iterative marginal probability estimation over factor graphs.
   - Post-processed by ordered statistics Gaussian elimination when belief propagation fails to converge due to short cycles in the Tanner graph.

## 3. High-Performance C Fastpath (`src/`)

To support million-shot Monte Carlo threshold simulations, `braid` provides a fastpath C library:
- Symplectic inner products accelerated using 64-bit unsigned integer bit-parallel instructions (`uint64_t`), bitwise XOR, AND, and compiler-intrinsic population counts (`__builtin_popcountll`).
- Dense binary matrix Gaussian elimination over $\mathbb{F}_2$ using 64-bit word operations.
- Blossom matching algorithm optimized for grid graphs.

## 4. Software Boundaries and Dependencies

1. **Host Environment**: macOS (Darwin arm64) or Linux (x86-64 / aarch64).
2. **Languages**:
   - GAP 4.10+ (Primary computational algebra core)
   - C11 (Fastpath bitwise routines)
   - Python 3.8+ (CLI, test harness, benchmark runner)
   - HTML5 / Vanilla ES6 JavaScript (Zero-dependency visualizer)
3. **External Dependencies**: Standard C library (`libc`), Python standard library (`sys`, `os`, `json`, `math`, `unittest`, `argparse`). Zero proprietary dependencies.
