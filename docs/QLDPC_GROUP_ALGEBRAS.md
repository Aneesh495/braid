# Group-Algebra Quantum LDPC Codes and Homological Products

Quantum Low-Density Parity-Check (QLDPC) codes represent the frontier of scalable quantum error correction. While 2D topological codes are fundamentally constrained by the Bravyi-Poulin-Terhal bound ($k \cdot d^{2/(D-1)} = O(n)$, yielding $k = O(1)$ and $d = O(\sqrt{n})$ in 2D), QLDPC codes exploit non-local connectivity to achieve constant encoding rates ($k/n = \Theta(1)$) and linear minimum distances ($d = \Theta(n)$).

```
         Group Ring F_2[G] Generator Matrix Representation
   +---------------------------------+---------------------------------+
   |                                 |                                 |
   |      Circulant Matrix A(x)      |      Circulant Matrix B(x)      |  <--- H_X
   |                                 |                                 |
   +---------------------------------+---------------------------------+
   |                                 |                                 |
   |     Circulant Matrix B(x)^T     |     Circulant Matrix A(x)^T     |  <--- H_Z
   |                                 |                                 |
   +---------------------------------+---------------------------------+
```

## 1. Group Ring Algebraic Foundations

Let $G$ be a finite group of order $\ell = |G|$ and $\mathbb{F}_2$ be the binary field. The group algebra $\mathbb{F}_2[G]$ is the ring of formal linear combinations:

$$a = \sum_{g \in G} a_g g, \quad a_g \in \mathbb{F}_2$$

Addition is component-wise XOR, and multiplication is governed by group composition:

$$a \cdot b = \sum_{g, h \in G} a_g b_h (g \cdot h)$$

For cyclic groups $G = \mathbb{Z}_\ell = \langle x \mid x^\ell = 1 \rangle$, the group ring is isomorphic to the quotient polynomial ring:

$$\mathbb{F}_2[\mathbb{Z}_\ell] \cong \mathbb{F}_2[x] / (x^\ell - 1)$$

Every element $a(x) = \sum_{i=0}^{\ell-1} a_i x^i$ induces a regular permutation representation matrix $M(a) \in \mathbb{F}_2^{\ell \times \ell}$ that is a circulant matrix:

$$M(a)_{i, j} = a_{(j - i) \bmod \ell}$$

The algebraic transpose corresponds to group inversion: $a^*(x) = \sum_i a_i x^{-i} = a(x^{-1})$.

## 2. Generalized Bicycle (GB) Codes

Generalized Bicycle codes, introduced by Panteleev and Kalachev (2021), define CSS quantum codes on $n = 2\ell$ qubits using two group algebra polynomials $A, B \in \mathbb{F}_2[G]$:

$$H_X = \begin{bmatrix} A & B \end{bmatrix}, \quad H_Z = \begin{bmatrix} B^* & A^* \end{bmatrix}$$

### Commutativity Condition Proof
For any CSS code, the parity check matrices must satisfy $H_X \cdot H_Z^T = 0 \pmod 2$.

$$\begin{aligned}
H_X \cdot H_Z^T &= \begin{bmatrix} A & B \end{bmatrix} \begin{bmatrix} (B^*)^T \\ (A^*)^T \end{bmatrix} \\
&= A \cdot (B^*)^T + B \cdot (A^*)^T
\end{aligned}$$

Since $(M^*)^T = (M^T)^T = M$ for group rings, $(A^*)^T = A$ and $(B^*)^T = B$:

$$H_X \cdot H_Z^T = A \cdot B + B \cdot A$$

When the group $G$ is Abelian (such as $\mathbb{Z}_\ell$), multiplication is commutative:

$$A \cdot B = B \cdot A \implies A \cdot B + B \cdot A \equiv 0 \pmod 2$$

Therefore, mutual commutativity between all X-stabilizers and all Z-stabilizers is guaranteed by the commutativity of the underlying group ring.

## 3. Hypergraph Product (HGP) Codes

Given two classical linear codes $\mathcal{C}_1$ and $\mathcal{C}_2$ defined by check matrices $H_1 \in \mathbb{F}_2^{r_1 \times n_1}$ and $H_2 \in \mathbb{F}_2^{r_2 \times n_2}$, the Tillich-Zemor Hypergraph Product constructs a CSS quantum code with:

$$n = n_1 n_2 + r_1 r_2$$

The parity check matrices are defined via Kronecker products:

$$H_X = \begin{bmatrix} H_1 \otimes I_{n_2} & I_{r_1} \otimes H_2^T \end{bmatrix}$$
$$H_Z = \begin{bmatrix} I_{n_1} \otimes H_2 & H_1^T \otimes I_{r_2} \end{bmatrix}$$

### Orthogonality Verification
$$\begin{aligned}
H_X \cdot H_Z^T &= (H_1 \otimes I_{n_2})(I_{n_1} \otimes H_2)^T + (I_{r_1} \otimes H_2^T)(H_1^T \otimes I_{r_2})^T \\
&= (H_1 \otimes I_{n_2})(I_{n_1} \otimes H_2^T) + (I_{r_1} \otimes H_2^T)(H_1 \otimes I_{r_2}) \\
&= (H_1 \cdot I_{n_1}) \otimes (I_{n_2} \cdot H_2^T) + (I_{r_1} \cdot H_1) \otimes (H_2^T \cdot I_{r_2}) \\
&= H_1 \otimes H_2^T + H_1 \otimes H_2^T \equiv 0 \pmod 2
\end{aligned}$$

The code parameters are $[[n_1 n_2 + r_1 r_2, k_1 k_2, \min(d_1, d_2)]]$. When based on expander codes, HGP codes provide constant encoding rate $k = \Theta(n)$ and linear distance $d = \Theta(\sqrt{n})$.

## 4. Tanner Graph Topology and Girth Bounds

The Tanner graph $\mathcal{G} = (V, E)$ of a QLDPC code is a bipartite graph between variable nodes (qubits) and check nodes (stabilizers).

1. **Check Weight Sparsity**:
   Every row and column of $H_X$ and $H_Z$ has weight bounded by a constant $w = O(1)$ independent of code length $n$.

2. **Cycle Girth Bounds**:
   Short cycles of length 4 (trivially generated by two checks sharing two qubits) correlate error symptoms and degrade iterative Belief Propagation (BP) decoding. Group ring polynomials $A(x)$ and $B(x)$ are chosen with cyclotomic properties to eliminate 4-cycles, ensuring girth $g \ge 6$.

3. **Decoding via BP-OSD**:
   Iterative marginal belief propagation coupled with Ordered Statistics Decoding (OSD) resolves degeneracies in $O(n^3)$ operations, achieving thresholds near $8.5\%$ under phenomenological noise.
